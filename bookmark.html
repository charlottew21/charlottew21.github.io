Link to Bookmark Project

This project is our bookmark that we created for Eshleman Elementary nearby. We were to create a fun and or inspirng bookmark for the kids to enjoy. We had a small group where we put all our bookmarks on a template and we got to use the offset printing press. Each of us also got to use an industrial paper cutter which we were all nervous to use at first but it was fun. These bookmarks were donated to the schools library for the kids to have.
