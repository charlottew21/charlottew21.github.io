Link to Infographic Project

This project was where we had to choose a form of communication and create a infographic all about how it works, why, impacts, and how it fits in the communication systems model. I chose to do cellphones and I made my project super fun and bright looking. When the professor said we were having a contest I was like "okay, I dont think mine will get anywhere though." Turns out it ended up winning first place haha. This was a fun project though since I was able to be creative and design it fully by myself.
